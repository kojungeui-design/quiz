시험실 담당자용 · 자동 추출 편

시험 데이터를
자동으로 뽑기 (CSV 만들기)

컴퓨터가 스스로 클릭해서 시험 데이터를 CSV로 저장해요.
실행하면 손만 떼고 기다리면 됩니다.

시작 전, 딱 3가지 약속

1 마우스·키보드를 건드리지 마세요. 컴퓨터가 대신 클릭하는 중이라, 건드리면 엉뚱한 곳을 눌러요. 실행하면 손 떼고 지켜보기!
2 화면에 회로 목록이 보이는 상태여야 해요. 다른 창은 닫아주세요.
3 뭔가 이상하면 멈추고 담당자를 부르세요. 무리해서 계속하지 않기.
참고
로그인 창이 떠 있어도 괜찮아요. 프로그램이 알아서 로그인하고 시작합니다.
1

BTS-600 회로 목록 화면 띄우기

회로들이 쭉 나열된 화면을 띄워 두세요. (다른 창은 닫기)

Batt0007DCHBatt0008CHA
Batt0009STOBatt0010DCH
Batt0011CHABatt0012STO
이런 회로 목록 화면이 보이면 준비 완료
2

export_all 을 두 번 클릭

export_all 파일을 두 번 클릭하세요.

▶
export_all
전 회로 자동 export - 4초 후 시작. 마우스를 건드리지 마세요!
화면 왼쪽 위에 위 같은 노란 안내글이 잠깐 떠요.
3

손 떼고 기다리기

4초 뒤 컴퓨터가 스스로 회로를 하나씩 열어 저장합니다. 마우스가 혼자 움직이는 건 정상이에요!

[3] export 중... (완료 2, 마지막 Circ0009)
회로 하나에 약 20초 — 40개면 15분쯤 걸려요.
지금 절대 마우스·키보드 만지지 마세요. 자리를 비워도 괜찮아요 — 알아서 합니다.
4

"완료!" 뜨면 끝

다 되면 전 회로 export 완료! 안내가 떠요. 이제 마우스 만져도 됩니다.

✔ 전 회로 export 완료! 성공 32 / 건너뜀 2 / 실패 0
✔ E:\bts_csv 폴더에 CIRC0007.csv, CIRC0008.csv ... 가 쌓였으면 성공! (기록은 같은 폴더 _all_log.txt)

이럴 땐 이렇게

마우스가 엉뚱한 곳을 클릭해요
화면 위치(좌표)가 안 맞는 거예요. 담당자에게 "영점(좌표)이 안 맞아요"라고 전하면 다시 맞춰 줍니다.
"Application Error" 에러창이 떠요
시험기 프로그램이 잠깐 멈춘 거예요. 자동으로 닫고 다시 시도합니다. 계속 반복되면 멈추고 담당자를 부르세요.
"건너뜀"이 많아요
데이터가 아주 큰 시험은 시간이 오래 걸려 건너뜁니다. 꼭 필요하면 담당자에게 "대기시간 늘려주세요"라고 전하세요.
중간에 급히 멈추고 싶어요
화면 오른쪽 아래 시계 옆의 파란 AutoIt 아이콘을 마우스 오른쪽 클릭 → Exit 를 누르면 멈춰요.
