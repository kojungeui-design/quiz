# Windows 작업 스케줄러 등록 (매일 자동 실행)

Windows 7 기준. 매일 정해진 시간에 `run_daily.bat`을 자동 실행한다.

## GUI로 등록 (쉬움)

1. 시작 → "작업 스케줄러" 검색 → 실행
2. 오른쪽 **[기본 작업 만들기]** 클릭
3. 이름: `BTS600 일일 시험현황` → 다음
4. 트리거: **매일** → 다음 → 시작 시간 **08:00** → 다음
5. 동작: **프로그램 시작** → 다음
6. 프로그램/스크립트: `C:\BTS-600\automation\run_daily.bat` → 다음 → 마침
7. 등록 후 작업 속성에서:
   - **"가장 높은 권한으로 실행"** 체크 (BTS-600 창 제어 위해)
   - "사용자가 로그온한 경우에만 실행" 유지 (화면 자동화는 로그인 상태 필요)

## 명령줄로 등록 (한 줄)

관리자 명령 프롬프트에서:
```
schtasks /create /tn "BTS600_Daily" /tr "C:\BTS-600\automation\run_daily.bat" /sc daily /st 08:00 /rl highest
```

## 주의사항

- **AutoIt 화면 자동화**를 쓰면 그 시간에 PC가 **켜져 있고 로그인**돼 있어야 함
  (화면 잠금 상태에서는 클릭이 안 될 수 있음 → 자동 로그인 또는 잠금 해제 유지)
- **Btsexp 명령줄**을 쓰면 화면 상태와 무관하게 실행 가능 (더 안정적)
- 첫 며칠은 로그(`C:\bts_csv\_export_log.txt`)와 결과 엑셀을 확인해
  40개 회로가 다 나오는지 점검

## 테스트

등록 후 작업을 우클릭 → **[실행]** 으로 즉시 한 번 돌려보고,
`C:\bts_csv\`에 CSV 40개와 `daily_status.xlsx`가 생기는지 확인한다.
