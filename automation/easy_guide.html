🔧 BTS-600 자동 다운로드 완성하기

어려운 코딩은 제가 합니다. 아래 쉬운 4단계만 따라 하고 캡처를 보내주세요.

👤 사용자님이 할 일 (쉬움) 프로그램 하나 설치 → 마우스로 5곳 가리키기 → 캡처 5장 보내기. 코딩 없음.
🤖 제가 할 일 (어려움) 캡처를 받아 자동화 스크립트를 완성해서 돌려주기. 사용자님은 더블클릭만.
1

AutoIt 설치하기 무료 · 5분

인터넷 검색창에 AutoIt download 검색 → 공식 사이트 접속

🔗 www.autoitscript.com/site/autoit/downloads

"AutoIt" 다운로드 → 받은 파일 실행 → 설치 화면에서 계속 Next(다음)만 누르면 끝.

2

Window Info 도구 열기

시작 메뉴에서 "AutoIt Window Info" 검색 → 실행. 작은 창이 하나 뜹니다.

이 도구는 화면의 버튼이 뭔지 알려주는 돋보기 같은 것입니다.

3

BTS-600 Export 창 띄워두기

BTS-600에서 배터리 하나 선택 → Export 버튼 클릭 → "Battery - Data export" 창이 뜬 상태로 그대로 둡니다.

4

5곳을 가리키고 캡처하기 가장 중요

Window Info 창에 있는 "Finder Tool"(과녁 🎯 모양)을 마우스로 꾹 눌러 끌어서 아래 5곳에 하나씩 올려놓으세요. 올려놓을 때마다 정보가 바뀝니다. 그때마다 화면 전체를 캡처하면 됩니다.

1 Export 창의 Convert to 드롭다운 (Excel 이라 써진 곳)
2 Export 창의 Destination file 입력칸 (E:\... 경로 쓰는 곳)
3 Export 창의 Ok 버튼
4 (Export 창 닫고) Test sections 창의 Export 버튼
5 왼쪽 위 배터리 목록 (Batt0011 써진 곳)
💡 어렵게 생각 마세요. 과녁을 올려놓은 채로 화면 캡처만 하면 됩니다. Window Info 창의 글씨가 안 보여도 괜찮으니, 화면 전체를 크게 캡처해 주세요.
✅ 캡처 5장을 이 채팅에 올려주세요 그러면 제가 자동화 스크립트를 완성해서 보내드립니다. 사용자님은 그걸 더블클릭만 하면 매일 자동 실행됩니다.
