# ② CSV → "측정값 표시" 엑셀 리포트

BTS-600 이 export 한 CSV 를 **사용자님이 손으로 만들던 "○○ - 표시.xlsx"** 와
똑같은 형식으로 자동 변환한다. 값을 요약/가공하지 않고 **원본 그대로** 옮기므로
값이 정확하고(검증: 원본과 0건 불일치), 핵심 측정 지점만 노란색으로 표시한다.

> 기존 ①번(일일 현황) 요약 리포트가 "너무 간단하고 값이 맞는지 모르겠다" 던 문제 해결본.
> ①번(진행현황 모니터링)과 ②번(정밀 표시 리포트)은 **둘 다** 쓴다.

## 실행 방법

### ⭐ 무설치(권장) — 파이썬 없이, AutoIt + Excel 만으로
그 PC에 이미 있는 **AutoIt(자동추출용)과 Excel** 로 동작한다. 파이썬 설치 불필요.
- **가장 쉬움**: `make_report.bat` 에 CSV 파일을 마우스로 **끌어다 놓기**
  → AutoIt 이 CSV 를 읽어 표시할 행을 계산 → Excel 이 그 행을 노랗게 칠하고
  같은 폴더에 `파일이름 - 표시.xlsx` 저장
- **폴더 통째로**: `make_report.bat` 더블클릭 → `E:\bts_csv` 안 모든 CSV 처리
- 파일: `make_report.au3`(핵심), `make_report.bat`(실행 래퍼)
- ※ Excel 이 설치되어 있어야 함(리포트를 여는 그 엑셀).

### (선택) 파이썬 버전 — 별도 PC/서버에서 대량 처리할 때
```
python make_display_report.py  파일.csv
python make_display_report.py  E:\bts_csv          (폴더 전체)
python make_display_report.py  수명시험.csv --cyc 5  (N사이클 간격 표시)
```
표시 규칙·결과는 무설치 버전과 동일(Excel 없이 openpyxl 로 생성).

## 표시(노란색) 규칙

| 시험 종류 | 판별 | 표시되는 행 |
|---|---|---|
| **용량/RC/단일 시험** (C20, RC, 충전수입성 …) | 최대 사이클 ≤ 1 | 첫 시험 블록 시작 + 각 스텝(충전·방전·휴지) **완료점**. 시작 전 대기(PAU)·마지막 정지(STO)는 제외 |
| **수명/반복 시험** (DoD …) | 최대 사이클 ≥ 2 | **N 사이클마다** 그 사이클의 방전 종료행 (`--cyc N`, 기본 5) |
| **CCA 냉간시동** (ENCCA, SAECCA …) | 방전전류 > 100A | 크랭킹 방전의 **시작·5초·10초·30초** 전압 + 지구력 방전 **종료점** |

> **J2801 은 대상에서 제외** — 파일명에 `J2801` 이 있으면 자동으로 건너뛴다.

### CCA(냉간시동전류) 검증 결과
- `ENCCA1` → **100% 일치** ✓ (시작·5초·10초·지구력방전종료)
- `ENCCA2` → 크랭킹 시작 중복행 1칸 차이 (전압 값은 동일)
- `SAECCA1` → 0/5/10/30초 전압 + 방전종료(53초, 7.2V 컷오프) 자동 추출
- 0.1초 간격 로깅도 정확한 5.0·10.0·30.0초 지점을 집는다.

### 검증 결과 (사용자님 수기 표시본과 비교)
- `0C20`, `0RC` → **100% 일치** ✓
- `1C20`, `1RC`, `0C20-RC` → 스텝 경계에서 ±1행 차이
  (BTS 가 스텝 끝에 같은 값을 한 줄 더 찍는 중복행 / 초기값 표시 여부 차이일 뿐,
   **표시된 값 자체는 동일**)
- 수명시험(DoD/J2801)은 프로토콜마다 표시 지점이 달라 `--cyc` 로 간격을 맞춘다.

## 데이터 정확도

- CSV 의 모든 행·모든 값을 그대로 엑셀에 옮김 (원본 대비 **0건 불일치** 확인).
- 시각(Time)은 시:분:초, 경과시간(Step/Program time)은 24시간 넘어도 정확히 누적,
  전압·전류·용량은 숫자로 저장 → 엑셀에서 바로 계산·그래프 가능.

## 파이썬 없이 쓰려면 (BTS PC 무설치)

1. **무설치 파이썬**(embeddable) 폴더를 `automation\python\` 에 두고 `openpyxl` 만 넣으면
   `make_report.bat` 이 자동으로 그 파이썬을 쓴다 (설치 불필요).
2. 또는 안전하게 **별도 PC/공유폴더**에서 돌린다:
   BTS PC 는 export 만(CSV) → 다른 PC 가 `make_report.bat` 으로 표시 엑셀 생성.
   (시험 장비를 전혀 안 건드림)
