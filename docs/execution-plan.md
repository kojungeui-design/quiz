## 3. 파일럿 결과 보고서 — 판정 기준 (12주차)

파일럿 종료 시 아래 숫자로 GO / 보완 / 중단을 판정한다.

| 지표 | GO (확산 착수) | 보완 후 재평가 | 중단 검토 |
|---|---|---|---|
| 주간 활성 사용자 (20명 중) | 10명+ | 5~9명 | 5명 미만 |
| 답변 👍 비율 | 80%+ | 60~79% | 60% 미만 |
| 출처 포함 답변 비율 | 95%+ | 85~94% | 85% 미만 |
| "담당자에게 묻지 않고 해결" 응답 | 30%+ | 15~29% | 15% 미만 |

## 4. 역할 분담 (RACI 요약)

| 역할 | 담당 | 책임 범위 |
|---|---|---|
| 프로젝트 오너 (R/A) | 기획 담당(본인) | 일정, 산출물, 경영 보고 |
| 개발 (R) | FE 1 + BE 1 | MVP 구현, 아키텍처 |
| 도메인 검수 (C) | 제품개발 부서 담당자 1 | 데이터 인벤토리, 답변 품질 검수 |
| 보안/법무 (C) | 정보보안팀 | LLM 계약, 가이드라인 |
| 스폰서 (I/A) | 경영진 | 승인, 예산, 확산 결정 |

> 개발 인력을 아직 확보하지 못한 경우: 5~10주차를 외주 또는 사내 타 팀 협조로 대체하되, PRD·아키텍처 산출물(2~4주차)은 반드시 내부에서 확정한 후 발주한다.
