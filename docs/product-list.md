# 만들 것 리스트 v2 — "일을 대신 하는" 업무 에이전트

- 작성일: 2026-07-21 (v2 — 챗봇 중심안 폐기, 업무 수행형 에이전트로 재정의)
- 원칙: **에이전트의 아웃풋은 답변이 아니라 "업무 결과물"이다** (문서 초안, 판정표, 분석 보고서)
- Q&A 챗봇은 각 에이전트에 딸린 서브 기능(인터페이스)으로만 존재

## 1. 고객 요구사항(SOR) 분석 에이전트 — 수주 검토 자동화

- **누가**: 제품개발·영업기술 (OEM 수주 검토 담당)
- **지금 하는 방식**: OEM이 보낸 수백 페이지 요구사양서(SOR)를 엔지니어가 며칠간 정독하며 우리 제품 사양과 하나하나 대조
- **에이전트가 하는 일**:
  - 입력: OEM 요구사양서 PDF 업로드
  - 처리: 요구항목을 자동 추출해 항목별 표로 정리 → 우리 제품 사양 DB와 자동 대조 → 충족/미충족/확인필요 분류
  - **아웃풋: 요구사항 대응표(Compliance Matrix) 엑셀 초안 + 미충족 항목 리스크 요약**
- **효과**: 수주 검토 기간 일 단위 → 시간 단위. 항목 누락(수주 후 발견되는 최악의 사고) 방지

## 2. 시험성적서·기술문서 자동 작성 에이전트

- **누가**: 제품개발·시험 담당
- **지금 하는 방식**: 시험 데이터(엑셀)를 보고 규격 기준과 대조한 뒤 성적서 양식에 수작업 입력
- **에이전트가 하는 일**:
  - 입력: 시험 원시 데이터(CSV/엑셀) + 적용 규격 선택
  - 처리: 규격 기준값과 자동 대조·합부 판정 → 회사 양식에 맞춰 성적서 초안 생성 → 판정 근거(규격 조항) 각주 표기
  - **아웃풋: 시험성적서 초안(회사 양식) + 판정 요약. 담당자는 검토·서명만**
- **효과**: 성적서 1건당 작성 시간 대폭 절감, 전기(轉記) 오류 제거

## 3. 규격·규제 변경 감시 에이전트 — 매주 자동 보고

- **누가**: 제품개발·품질·인증 담당
- **지금 하는 방식**: 규격 개정을 뒤늦게 알게 되거나, 담당자가 틈틈이 확인. 개정 시 어떤 제품이 영향받는지 수작업 파악
- **에이전트가 하는 일** (사람이 시키지 않아도 매주 자동 실행):
  - 처리: 관련 규격(EN/IEC/KS/JIS, 배터리 환경규제 등) 개정 여부 감시 → 개정되면 구버전과 차이 분석 → 사내 제품·문서 중 영향받는 항목 매칭
  - **아웃풋: 주간 "규격 변경 영향 보고서" — 무엇이 바뀌었고, 우리 제품 어디에 영향이며, 뭘 해야 하는지 액션 리스트 포함. 담당자 메일로 자동 발송**
- **효과**: 규제 대응 리스크(인증 실효, 납품 중단)의 조기 경보 체계

## 4. 품질 클레임 분석 에이전트 — 유사사례 검색 + 8D 초안

- **누가**: 품질보증·CS 담당
- **지금 하는 방식**: 클레임 접수 → 과거 유사 사례를 기억과 엑셀 검색에 의존 → 원인분석 보고서(8D 등) 처음부터 작성
- **에이전트가 하는 일**:
  - 입력: 클레임 접수 내용(증상, 제품, 사용 환경)
  - 처리: 과거 클레임 DB에서 유사 사례·당시 원인·대책 검색 → 발생 경향 통계(제품별/원인별/기간별) 분석 → 원인 후보 제시
  - **아웃풋: 유사사례 분석 리포트 + 8D 보고서 초안(D1~D3 자동 채움) + 월간 클레임 경향 대시보드**
- **효과**: 초동 대응 속도 향상, 재발성 문제의 조기 발견

## 5. 시험 데이터 상시 분석 에이전트 — 이상 조기 감지

- **누가**: 시험실·제품개발
- **지금 하는 방식**: 수명시험 등 장기 시험 데이터를 주기적으로 열어보고 판단. 이상 징후를 뒤늦게 발견하면 시험 기간 손실
- **에이전트가 하는 일** (상시 자동 실행):
  - 처리: 축적되는 시험 데이터를 상시 감시 → 규격 이탈 추세·이상 패턴 감지 시 즉시 알림 → 주간 시험 현황 자동 집계
  - **아웃풋: 이상 감지 즉시 알림(어느 시료, 어떤 항목, 추세 그래프 첨부) + 주간 시험 현황 보고서 자동 생성**
- **효과**: 실패 시험의 조기 중단으로 시험 리소스 절약, 보고서 작성 업무 제거

## 6. 기술 동향·경쟁사 리서치 에이전트 — 매주 월요일 브리핑

- **누가**: 제품개발·기획·경영진
- **지금 하는 방식**: 개인이 틈틈이 뉴스·논문·특허 검색, 체계적 축적 없음
- **에이전트가 하는 일** (매주 자동 실행):
  - 처리: 지정 키워드(경쟁사, AGM/EFB, 보조배터리, 재활용 규제 등)로 뉴스·특허·규제 동향 수집 → 중요도 선별 → 우리 사업에 주는 시사점 정리
  - **아웃풋: 주간 기술동향 브리핑(A4 2장) — 월요일 아침 자동 발송. 과거 브리핑은 검색 가능한 아카이브로 축적**
- **효과**: 전담 인력 없이 상시 시장 감시 체계 확보

## 7. 보고서·품의서 초안 작성 에이전트

- **누가**: 전 부서 (전사 확산용)
- **지금 하는 방식**: 출장보고서, 회의록, 품의서를 매번 백지에서 작성
- **에이전트가 하는 일**:
  - 입력: 메모·녹취·데이터 등 재료를 던져주면
  - 처리: 회사 양식·과거 결재 통과 문서의 톤에 맞춰 초안 작성
  - **아웃풋: 사내 양식에 맞는 문서 초안 (회의록은 결정사항·액션아이템·담당·기한 자동 정리)**
- **효과**: 문서 작성 시간 절반 이하. 전사 직원이 매일 체감하는 확산용 제품

## 서브 기능 (모든 에이전트 공통)

- 사내 문서 Q&A 채팅: 각 에이전트 화면에 붙는 보조 기능 (v1의 "챗봇"은 이 위치로 격하)
- 교육 튜터/문항 생성: 교육팀 요청 시 부가 모듈로 제공 (기존 퀴즈 앱 자산 활용)

## 우선순위 제안

| 순위 | 제품 | 이유 |
|---|---|---|
| 1차 (파일럿) | **② 시험성적서 자동 작성** | 아웃풋이 명확(성적서), 효과 측정 쉬움, 데이터가 사내에 이미 존재 |
| 1차 (파일럿) | **① SOR 분석** | 수주 검토라는 고가치 업무 직결, 경영진 설득력 최고 |
| 2차 | ③ 규격 감시, ⑤ 시험 데이터 감시 | 자동 실행형 — 운영 노하우 축적 후 |
| 3차 (전사) | ⑦ 문서 초안, ④ 클레임 분석 | 전사 체감 + 품질 DB 정비 필요 |
| 상시 | ⑥ 기술동향 브리핑 | 구축 난도 낮음, 이르게 시작해 존재감 확보 가능 |

> 파일럿 후보 ①②는 실제 업무 데이터(과거 SOR, 시험 데이터·성적서 샘플)를 확보할 수 있는지가 착수 조건. 확보가 빠른 쪽부터 시작한다.
