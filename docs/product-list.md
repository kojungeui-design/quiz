# 만들 것 리스트 (제품 카탈로그)

- 작성일: 2026-07-21
- 하나의 플랫폼 위에 올라가는 7개 제품(기능). 번호 순서 = 개발 우선순위.

| # | 제품 | 사용자 | 하는 일 | 데이터 | 시기 |
|---|---|---|---|---|---|
| 1 | 사내 지식 Q&A 챗봇 | 제품개발 20명 → 전 직원 | 질문하면 회사 문서 기반으로 답 + 출처 표기 | 교육자료, 규격, FAQ | 파일럿 (5~10주) |
| 2 | 관리자 콘솔 | 부서 담당자 | 문서 업로드→자동 색인, 대화 로그/만족도 조회 | — | 파일럿에 최소 기능 포함 |
| 3 | AI 학습 튜터 + 문항 자동 생성 | 교육생, 교육 담당자 | 오답 해설·재출제, 교재 업로드 시 평가 문항 자동 생성 | 기존 퀴즈 앱 + 교재 | 파일럿 직후 |
| 4 | 인사/총무 문의 챗봇 | 전 직원 | 휴가·복리후생·서식 등 규정 문의 1차 응대 | 취업규칙, 사내 규정 | 전사 확산 1호 |
| 5 | IT 헬프데스크 챗봇 | 전 직원 | PC·계정·보안 문의 1차 응대 | IT FAQ, 보안 정책 | 전사 확산 2호 |
| 6 | 데이터 분석 도우미 | 엔지니어, 품질, 영업 | 엑셀/CSV 업로드 → 요약, 이상치, 기준 대비 판정 보조 | 사용자 업로드 파일 | 확산 이후 |
| 7 | 영업 기술지원 챗봇 | 영업, (향후) 대리점 | 제품 사양 비교, 적용 차종 확인, 견적 자료 초안 | 카탈로그, 사양 DB | 확산 이후 |

## 구조

```
[공통 플랫폼]  로그인(SSO) · 채팅 화면 · 문서 색인 · 권한 · 로그
     │
     ├─ 1. 지식 Q&A (제품개발)   ← 파일럿, 여기서 검증
     ├─ 3. 학습 튜터 (교육)
     ├─ 4. 인사/총무 챗봇
     ├─ 5. IT 헬프데스크
     ├─ 6. 데이터 분석
     └─ 7. 영업 기술지원
```

- 1번과 2번이 "엔진". 나머지는 같은 엔진에 부서 문서만 바꿔 얹는 것이라 개발비가 거의 추가되지 않음.
- 그래서 순서가 중요: 1~2번을 파일럿으로 검증한 뒤 3번(자산 보유)과 4~5번(효과 체감 큰 전사 서비스)으로 확산.
