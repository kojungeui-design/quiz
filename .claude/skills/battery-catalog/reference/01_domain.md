# 도메인 — 규격 · 성능 · 스키마

## 1. 규격(사이즈) 마스터 49종

치수는 **규격 마스터에만** 둔다. 모델 행은 스펙만 들고 있고 L×W×H 는 규격에서
물려받는다. 그래야 같은 규격끼리의 비교와 차량 매칭이 자동으로 붙는다.

### JIS (일본 — 한국·동남아 공용)

`B17` `B19` `B20` `B24` `D20` `D23` `D26` `D31` `E41` `F51` `G51` `H52`

읽는 법: 앞 문자 = 단면 크기 등급, 숫자 = 길이(cm). `D23` = D 단면 · 길이 23cm.
표준값 예: B19 33Ah/330CCA(SAE)/9.6kg · D23 60Ah/550 · D26 70Ah/620 ·
D31 90Ah/730 · E41 100Ah/750 · G51 150Ah/900 · H52 200Ah/1150

### JIS-ISS (아이들링스톱 전용 — EFB/AGM)

`K-42` `M-42` `N-55` `Q-85` `S-95` `T-110`

일반 JIS 와 케이스가 다르다. **ISS 차량에 일반 액식을 물리면 안 된다.**
표준값 예: M-42 38Ah/400 · N-55 48Ah/470 · Q-85 60Ah/650 · S-95 75Ah/730 ·
T-110 85Ah/790

### DIN/EN (유럽)

`LN0` `LN1` `LN2` `LN3` `LN4` `LN5` `LN6` · `LBN1` `LBN2` `LBN3` `LBN4` ·
`EN A` `EN B` `EN C` `EN D`

`LBN` = LN 의 저상(low box) 판. 표준값 예: LN1 50Ah/450(EN) · LN2 62Ah/540 ·
LN3 74Ah/680 · LN4 80Ah/740 · LN5 95Ah/800 · LN6 110Ah/880

**ETN 6자리 코드**도 같이 다룬다: `560 127 054` = 앞3자리(전압·용량 코드) +
중간3자리(설계 변형) + 뒤3자리(CCA÷10). 유럽 카달로그는 ETN 으로 검색한다.

### BCI (북미)

`BCI 24` `25` `27` `31` `34` `35` `47` `48` `49` `51R` `58` `65` `75` `78` `94R` · `8D`

`R` 접미사 = 단자 좌우 반전. 표준값 예: BCI 24 70Ah/650(SAE) · BCI 34 50Ah/700 ·
BCI 48 70Ah/730 · BCI 65 75Ah/750 · BCI 94R 80Ah/800 · BCI 31 100Ah/800

### 스키마

```js
{k:'D23', sys:'JIS', L:232, W:173, H:225, ah:60, note:'승용 표준'}
```

## 2. CCA — EN 과 SAE 는 다른 시험이다

| 규격 | 시험 조건 |
|---|---|
| EN | -18°C, **10초** 후 단자전압 7.5V 이상 |
| SAE | -18°C, **30초** 후 단자전압 7.2V 이상 |

**정확한 환산식은 없다.** 그런데 카달로그를 섞어 모으면 한 축에서 봐야 한다.
그래서:

- 원 표기값(`cca`)과 **표기 규격(`cs`: 'EN'|'SAE')을 항상 같이 저장**한다.
- 비교할 때만 근사 계수(기본 **0.95**, 설정에서 조절)로 환산한다.
- 환산된 값에는 화면에 `환산값` 표시를 남기고 원 표기값을 같이 보여준다.
- 계수를 코드에 박지 말고 [설정] 에 노출한다.

## 3. 파생지표 — 값이 아니라 계산으로

| 지표 | 식 | 뜻 |
|---|---|---|
| CCA/Ah | `cca / ah` | 시동성 밀도. 높을수록 시동 특화 |
| Wh/kg | `v * ah / wt` | 중량 에너지밀도 |
| Wh/L | `v * ah * 1e6 / (L*W*H)` | 체적 에너지밀도 (치수는 규격에서) |

**상대 점수는 반드시 용도군 안에서만 낸다.** 승용 SLI 와 상용차를 한 축에
놓고 점수를 매기면 의미가 없다. 같은 `app` 그룹 안에서 min-max 정규화해
0~100 으로 뽑는다.

## 4. 판매지역 11개

```
KR 한국 · JP 일본 · CN 중화권 · SEA 동남아 · IN 인도 · EU 유럽
NA 북미 · LAT 중남미 · MEA 중동/아프리카 · OCE 오세아니아 · ETC 기타
```

모델은 지역을 **배열**로 갖는다(`rg:['EU','MEA']`). 한 모델이 여러 지역에
팔리는 게 정상이다. 국가 단위 지도용으로는 별도 `WORLD` 딕셔너리를 둔다:

```js
const WORLD = {'한국':[36.5,127.8,'KR'], '독일':[51.2,10.4,'EU'], ...};  // 위도,경도,지역키
```

## 5. 브랜드 × 마켓 — 이게 핵심 모델링이다

**같은 브랜드라도 나라마다 파는 시리즈와 규격체계가 다르다.** 브랜드 하나로
뭉치면 그 차이가 사라지고 "Bosch 정보가 없다" 는 착시가 생긴다.

Bosch 실례:

| 마켓 | 규격체계 | 시리즈 |
|---|---|---|
| 유럽 | DIN/EN + ETN | S3, S4, S5, S6 AGM, S4 EFB, T3·T4·T5(상용) |
| 북미 | BCI | S4, S5, S6 AGM, Platinum AGM |
| 인도 | DIN/EN + JIS | S3, S4, S5, S4+, S5+, T4(상용), M6(이륜) |
| 중남미 | BCI + 현지 | S3, S4, S5 |
| 중국 | DIN/EN 저상 | S3, S4, S5, AGM |
| 오세아니아 | DIN/EN + JIS | S4, S5, S5 AGM |
| 중동·아프리카 | DIN/EN | S3, S4, S5 |
| 동남아 | JIS + DIN | S3, S4, S5 |

스키마:

```js
{k:'bosch_eu', br:'Bosch', mk:'clarios', rg:'EU', ctry:'유럽',
 std:'DIN/EN', series:'S3, S4, S5, S6 AGM, S4 EFB',
 cat:'<실제 카달로그 URL>', fit:'<피트먼트 URL>',
 st:'확인됨', nsrc:4, catKind:'pdf', catChk:'검색확인'}
```

**주의: 브랜드 소유자와 제조 주체가 다를 수 있다.** 실제 사례 — 중동 ACDelco 는
ACDelco 가 아니라 사우디 MEBCO(Clarios 49% 합작)가 만든다. `mk` 는 브랜드
소유자가 아니라 **실제 만드는 곳**을 가리켜야 한다.

## 6. 데이터 스키마 전체

```js
// 규격
{k, sys, L, W, H, ah, note}

// 모델
{mk,   // 제조사 키
 br,   // 브랜드
 mdl,  // 모델명
 bm,   // 브랜드마켓 키 (선택)
 sz,   // 규격
 grp,  // 규격그룹 (치수 물려받는 키)
 tech, // FLD|EFB|AGM|AGM나선형
 app,  // 승용SLI|스타트스톱|상용차|마린/듀얼
 v,    // 전압 (12)
 ah, rc, cca,
 cs,   // 'EN'|'SAE'
 wt,   // kg
 cyc,  // 사이클 수 (선택)
 rg,   // 판매지역 배열
 ver,  // 근거등급 std|pub|est|slot|own|user
 srcDoc, srcPage}  // 근거 카달로그·페이지 (선택)

// 제조사/유통사
{k, n, c /*국가*/, t /*'M' 제조사 | 'D' 유통사*/, rg, br, site, st /*수집상태*/, ed /*판*/}

// 차량 적합성
{mkt,  // 시장
 bd,   // 브랜드(차)
 mdl, yr, eng,
 isg,  // 0|1 아이들링스톱 여부
 grp,  // 요구 규격
 ah, cca, tech,
 alt,  // 대체 규격
 conf} // 확신도 H|M|대조필요

// 유통사
{k, n, c, rg, site, list /*제품목록URL*/, pat /*브랜드페이지 패턴*/,
 br /*취급 브랜드 파이프 구분*/, chk /*검색확인|미확인*/, note}
```
