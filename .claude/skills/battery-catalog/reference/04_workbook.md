# 엑셀 워크북 — 12시트

앱과 **같은 시드**에서 굽는다. 앱 HTML 에서 시드 블록을 뽑아 JSON 으로 떨구고
(`tools/dump_seed.js`), 그 JSON 으로 워크북을 만든다(`tools/build_workbook.py`,
`openpyxl`). 두 산출물이 갈라지면 안 된다.

```bash
node tools/dump_seed.js battery_catalog.html seed.json
python3 tools/build_workbook.py seed.json 글로벌_SLI_배터리_카달로그.xlsx
```

## 왜 이렇게 나눴나

- **카달로그 시트의 판매지역은 지역마다 열이 따로다**(O 표시). 한 셀에
  `EU|MEA` 로 넣으면 필터가 안 걸린다. 텍스트 열도 하나 같이 두되 **REGIONS
  순서대로** 뽑아라 (순서가 어긋나면 원핫과 대조가 안 된다).
- **지역별판매(롱포맷)를 따로 둔다.** "유럽에서 파는 LN3, 70Ah 이상" 을 필터
  두 번으로 뽑는다. 피벗테이블 원본으로도 그대로 쓴다.
- **사이즈별요약**은 라인업 공백을 한눈에 보는 시트다.

## 수식 규칙 — 값을 박지 마라

파생지표와 집계는 **값이 아니라 수식**이어야 한다. 스펙을 고치면 갭·커버리지가
따라 움직여야 하기 때문이다. `openpyxl` 로 문자열 수식을 넣고
`wb.calculation.fullCalcOnLoad = True` 를 켠다.

### 쓰면 안 되는 함수

| 금지 | 이유 | 대신 |
|---|---|---|
| `MAXIFS` / `MINIFS` | Excel 2016+ 전용. `_xlfn.` 접두가 붙어 구버전에서 `#NAME?` | `SUMPRODUCT` |
| `IFS` / `TEXTJOIN` / `XLOOKUP` | 같은 이유 | `IF` 중첩 / `INDEX+MATCH` |
| 배열수식 `MIN(IF(...))` | Ctrl+Shift+Enter 가 필요 | `SUMPRODUCT` 변형 |

### 대체 패턴

조건부 최대:
```excel
=SUMPRODUCT(MAX((카달로그!$F$2:$F$900=$A2)*(카달로그!$L$2:$L$900)))
```

조건부 최소 (0 이 섞이는 걸 피하려고 뒤집는다):
```excel
=100000-SUMPRODUCT(MAX((카달로그!$F$2:$F$900=$A2)*(100000-카달로그!$L$2:$L$900)))
```

**Excel 2007 세대 함수만 쓴다** — `SUMPRODUCT` `SUMIFS` `COUNTIFS` `INDEX`
`MATCH` `IFERROR` `ROUND`. 이거면 다 된다.

## 검증

LibreOffice 가 있으면 헤드리스로 재계산해 값을 확인한다:

```bash
soffice --headless --convert-to xlsx --outdir /tmp out.xlsx
```

**없으면 없다고 말해라.** 대신 각 수식의 로직을 파이썬으로 복제해 앱이 계산한
값과 대조한다. 이때 주의:

> 파이썬 `round()` 는 **은행가 반올림**(round-half-to-even)이고 엑셀 `ROUND` 는
> 반올림 올림이다. `712.5` 가 파이썬에선 712, 엑셀에선 713 이 된다.
> 검증기에서는 `int(x + 0.5)` 를 써라. 안 그러면 없는 버그를 쫓는다.
