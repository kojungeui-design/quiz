## 1. 생성한 행을 JS 배열에 주입할 때 콤마 누락

스크립트로 만든 행을 문자열 치환으로 배열에 끼워 넣으면 마지막 행에 콤마가
빠져 `Unexpected token '{'` 가 난다. 두 번 당했다.

주입 후 후처리로 강제한다:
```python
# '{mk:' 로 시작하고 '}' 로 끝나는 줄에는 콤마를 붙인다
```
그리고 **반드시 `node --check` 로 문법을 본 뒤** HTML 을 조립해라.

## 2. 검색 입력의 `change` 가 클릭 대상을 파괴한다

타이핑 → 결과 행 클릭 → blur → `change` 발화 → 재렌더 → 그 행이 사라짐 →
클릭이 허공을 친다. 텍스트 입력은 `oninput`, 셀렉트·체크박스는 `onchange`.
→ `reference/02_app.md` 의 `bindFilter()`

## 3. `100Ah` 를 CCA 100 으로 읽는다

```python
r'(\d{3,4})\s*A(?![a-z])'   # 부정 선읽기가 없으면 Ah 를 A 로 읽는다
```

## 4. BCI 정규식이 문서의 모든 숫자를 삼킨다

`\b(\d{2,3})\b` 로 잡으면 페이지 번호·연도·전화번호가 전부 BCI 그룹이 된다.
`group` 키워드를 명시적으로 요구해라.

## 5. 사내 엑셀에 오타가 섞여 통계가 망가진다

C20 셀에 `1452` 가 들어 있어서 "D23 용량 57~1452Ah" 가 나왔다.
범위 가드(`SANE`)로 걸러내고 라벨값으로 폴백한다.

## 6. `MAXIFS` 는 구버전 엑셀에서 `#NAME?`

`_xlfn.MAXIFS` 로 저장돼 Excel 2016 미만에서 깨진다.
`SUMPRODUCT(MAX((조건)*(범위)))` 로 바꿔라. → `reference/04_workbook.md`

## 7. `MIN(IF(...))` 는 배열수식이라 그냥 넣으면 안 된다

`100000 - SUMPRODUCT(MAX((조건)*(100000-값)))` 로 뒤집는다.

## 8. 파이썬 `round()` 와 엑셀 `ROUND` 는 다르다

은행가 반올림 vs 반올림 올림. 검증에서 712 vs 713 로 갈려 없는 버그를 쫓았다.
검증기는 `int(x + 0.5)`.

## 9. 폰에서 가로 스크롤이 생긴다

`.g4`/`.g3` 만 2열로 바꾸고 `.g2` 를 그대로 두면 좁은 화면에서 넘친다.
`.g2 { grid-template-columns: 1fr; }` 와 `input[type=file] { max-width: 100% }`
까지 넣고, **뷰마다** `scrollWidth > clientWidth` 를 확인해라.

## 10. localStorage 가 15,000행에서 터진다

`QuotaExceededError` → `저장: 0.00 MB` → 새로고침에 전부 소실.
임포트 행은 **IndexedDB** 로. → `reference/02_app.md`

## 11. 16,000행을 한 번에 DOM 에 그리면 멈춘다

`CAT_PAGE = 300` 페이징 + "더 보기".

## 12. `file://` 에는 `crypto.subtle` 이 없다

보안 컨텍스트가 아니라서 SHA-256 이 안 돈다. 폰에 저장해서 여는 게 주 사용
시나리오이므로 **순수 JS SHA-256 폴백이 필수**다. NIST 벡터 3개로 검증해라.

## 그 밖에 조심할 것

- **원핫 열과 텍스트 열의 순서가 어긋난다.** 지역 텍스트를 만들 때도 `REGIONS`
  순서대로 뽑아라. 내용은 같은데 순서가 달라 105행이 불일치로 잡혔다.
- **CSV 의 BOM.** 엑셀 호환으로 BOM+CRLF 를 쓰면 `csv.DictReader` 가
  `'﻿유통사키'` 를 필드명으로 잡는다. `encoding='utf-8-sig'`.
  줄바꿈도 파일 전체를 CRLF 로 통일해라.
- **`__pycache__` 를 커밋한다.** `.gitignore` 에 `__pycache__/`, `*.pyc` 를
  먼저 넣어라. 이미 올렸으면 `git rm -r --cached`.
- **긴 국가 사전은 긴 이름부터.** `GUINEA` 가 `EQ. GUINEA` 를 먹는다.
- **LibreOffice 가 클라우드 환경에서 안 뜬다**(`failed to launch javaldx`).
  못 돌렸으면 못 돌렸다고 보고해라. 조용히 넘어가면 안 된다.
