# 전세계 SLI 배터리 카달로그 시스템

## 무엇을 만드는가

납축전지 제조사·유통사가 공개한 카달로그에서 SLI 배터리 스펙을 모아
**비교하고 · 차종에 물리고 · 지역별로 관리하고 · 근거를 남기는** 시스템.

산출물은 셋이고, **셋 다 내야 완료다.**

1. `battery_catalog.html` — 외부 자원 없는 단일 파일 웹앱 (폰에서 그대로 동작)
2. `글로벌_SLI_배터리_카달로그.xlsx` — 12시트 워크북 (집계가 값이 아니라 **수식**)
3. `tools/` — 수집 엔진 + 사내 자료 읽기 + 변환기 + 요약
4. **더블클릭 실행기 + 폴더 패키지** — 사용자가 명령줄 없이 쓸 수 있어야 한다

## 대상 범위 — 먼저 못 박는다

- **SLI(시동용)만.** 기술은 `FLD`(일반액식) / `EFB` / `AGM` / `AGM나선형` 넷.
- **딥사이클·산업용·OPzV·지게차·UPS 는 제외한다.** 요구가 없으면 넣지 마라.
- 용도군은 `승용SLI` / `스타트스톱` / `상용차` / `마린·듀얼` 넷.

## 순서

이 순서를 지켜라. 뒤 단계가 앞 단계 산출물을 먹는다.

1. **규격 마스터** — 49종 사이즈에 치수·표준 용량을 박는다 → `reference/01_domain.md`
2. **제조사·브랜드×마켓** — 브랜드가 아니라 **브랜드 × 국가**가 1급 단위다
3. **모델 시드** — 시리즈 × 규격 조합으로 골격을 세우고 `slot` 태그를 단다
4. **차량 적합성** — 차종 요구 스펙(규격·용량·CCA·ISG) 표
5. **유통사 레지스트리** — 유통사 한 곳이 같이 파는 브랜드 = 그 나라 경쟁 구도
6. **앱 구현** — 11개 뷰 → `reference/02_app.md`
7. **수집 엔진** — → `reference/03_collect.md`
8. **엑셀 워크북** — → `reference/04_workbook.md`
9. **검증** — 헤드리스 브라우저로 전 뷰 렌더·필터·정렬·임포트, JS 에러 0 확인
10. **전달** — 더블클릭 실행기·폴더 패키지·백업 안내 → `reference/06_delivery.md`

**0단계를 빠뜨리지 마라.** 시작하기 전에 **"사내에 이미 모아둔 카달로그가
있는지"** 물어봐라.  웹에서 주소를 찾는 것보다 그게 빠르고 정확하다.  실제로
Banner·FIAMM·Leoch·Camel 은 찾아낸 주소가 전부 404 였는데 사내에는 실물 PDF 가
있었다.  이걸 마지막에 깨달아서 시간을 크게 낭비했다.

작업 전에 `reference/05_pitfalls.md` 를 읽어라. 여기 적힌 건 전부 **실제로 밟은
지뢰**다. 안 읽으면 같은 자리에서 같은 시간을 태운다.

## 절대 어기면 안 되는 원칙

**1. 추정을 사실로 쓰지 마라.**
모든 스펙 행은 근거 등급을 달고 다닌다.

| 등급 | 뜻 |
|---|---|
| `std` | 규격 표준값 |
| `pub` | 제조사 공개 스펙 (카달로그 대조 완료) |
| `est` | 추정 |
| `slot` | 라인업 슬롯 — 그 브랜드가 그 규격을 판다는 것만 확인, 수치는 표준값 |
| `own` | 사내 설계치 |
| `user` | 사용자 직접 입력 |

`slot`·`est` 가 다수면 **대시보드 최상단에 그렇게 띄워라.** "카달로그 원본 대조
전에는 영업·기술 자료로 쓰면 안 된다" 를 앱이 직접 말해야 한다.

**2. 못 찾은 건 못 찾았다고 남겨라.**
바이어·유통사·URL 을 그럴싸하게 지어내면 근거 체계 전체가 무너진다.
공개 검색으로 특정 안 되는 건 레지스트리에 넣지 말고 README 에 미해결로 적는다.

**3. 카달로그 링크는 대표 홈페이지가 아니라 실제 카달로그 주소다.**
`bosch.com` 이 아니라 `.../batteries_s3s4s5_2pp_2017.pdf` 다.
존재를 확인한 것(`검색확인`)과 경로를 추정한 것(`패턴추정`)을 컬럼으로 구분한다.

**4. 공개 저장소에 사내 데이터를 커밋하지 마라.**
고객품번·납품처·오더량·바이어 실명 목록은 **변환 스크립트만** 올리고 결과는
사용자 기기에만 남긴다. 카달로그 PDF 원본은 제조사 저작물이라 `.gitignore`.

**5. 폰이 1급 환경이다.**
좁은 화면에서 표는 카드로, 메뉴는 하단 탭으로. 내보내기는 Web Share API 로
메신저에 바로 꽂히게. PDF 근거 등록도 폰에서 되게(브라우저가 직접 해시 계산).
