## 이것이 의미하는 것

담당자가 **로우데이터를 열어 눈으로 값을 찾아 관리대장에 옮겨적는 작업 전체가 자동화 가능**하다는 것이 실제 데이터로 증명됨.

- 값을 잘못 읽거나 잘못 옮겨적는 **전기(轉記) 오류 제거**
- 시료 1개당 관리대장 작성 시간 → 0에 수렴
- 사람은 검토·서명만
- CSV의 회로번호 → 관리대장 샘플 자동 매핑까지 가능

## 실행 방법

```bash
python3 bts600_extract.py L6n1.csv L6n3.csv   # 관리대장 값 자동 추출
python3 bts600_analyzer.py L6n1.csv L6n2.csv  # 이상 감지·판정 리포트
```

## 다음 빌드 단계

1. 추출값을 실제 xlsx 관리대장 템플릿의 해당 셀에 자동 기입 (openpyxl)
2. 회로번호 → 샘플 자동 매핑 테이블(모델별) 등록
3. 폴더 감시로 신규 CSV 자동 처리 → 관리대장 자동 갱신
4. 규격 기준값 대비 합부 판정 컬럼 추가
5. LLM으로 이상 패턴 해설 + 조치 제안
